> 为父母、长辈或自己写一本「普通人的人生传记」。
> **AI 不当枪手，当访谈官**——笔是委托人的，AI 只负责提问、追问、整理、提醒核对。

一个用于 WorkBuddy / 类 Claude Code 智能体的 **Skill（技能包）**。它把「给父母做口述史」
这件难事拆成可执行的流水线：定制访谈提纲 → 口述稿归位成时间线 → 家书与手写日记数字化
→ 原话保真成稿 → 四层质检 → 交付可打印成书。

---

## 为什么做这个

整理父母的一生，真正的难点不在文笔，而在三件事：

1. **问不出来**。泛泛地问「您小时候怎么样」，得到的永远是几句套话。
2. **记不准**。记忆会错，AI 也会错——硬编出来的细节比留白更糟。
3. **人会消失**。长辈走了、字认不出了、照片上的人没人认得了，这些线索就永久断了。

本技能针对这三点设计：**100 问访谈库**按老人年代与职业定制；**存疑一律留白 `[?]`
并列出候选**，机器只提示、不裁定；**家书 / 老照片 / 文档**都有专门的归档与锚定流程。

---

## 核心能力

| 分支 | 做什么 |
| --- | --- |
| **访谈** | 按年代、职业、方言生成个性化提纲（`references/interview-questions.md`，100 问库） |
| **时间线** | 口述录音稿归位到人生时间线，存疑处标注 `[?]`，不猜 |
| **家书 / 手写** | 转写存疑字**只标不改**；用户核对结果沉淀为「个人字形档案」，同一手迹越整理越准 |
| **老照片** | 原件与 AI 修复副本自动配对去重，按背面题字与家书线索锚定人物（**只提示不认定**），按服饰陈设与花期断代 |
| **文档** | 素材文档查重（SHA-256 精确重复 + 跨格式同文检测）与人物提及扫描 |
| **成稿** | 原话保真写作 + 四层质检（史实一致 / 原味保留 / 去 AI 腔 / 子女试读） |
| **交付** | 传记成稿、书版式页面（可打印 PDF）、家庭记忆档案 |

## 三条不可动摇的红线

这三条来自真实项目中的三次翻车，代价是档案里出现过与事实相反的句子：

1. **机器是提示器，不是裁判**。字形、逻辑、常识补全三条路都栽过——
   任何结论只能以 `[?]` + 候选 + 上下文提请裁决，**永不直接写入正文**。
2. **理由只能照录，禁止代拟**。凡「因为……所以……」入档，必须能追到一句原话；
   追不到就降级为「待核」。代拟的理由读来通顺、与结论不冲突，只有逐字回对原话才能发现。
3. **状态必须带时间维度**。残疾／健康／能力／职位一律记「某年之后怎样」，
   **严禁以晚年状态倒推早年能力**（曾据此把一个人认错）。

## 安装

把本仓库放到技能目录即可：

```bash
# WorkBuddy
git clone <本仓库地址> ~/.workbuddy/skills/parents-memoir
```

或下载 Release 里的 `parents-memoir.zip` 解压到同一目录。

**运行前提**：Python 3.9+，全部脚本**只用标准库**，开箱即跑。
唯一可选依赖是 `Pillow`（`pip install pillow`），仅老照片分支用它做相册整页裁单张。

## 隐私设计

- **脚本零内置数据**：人名库、字辈模板、已校正清单全部运行时从用户项目读取
  （`素材库/项目配置.md`），找不到就报错退出——**换一个家族也能直接用，不需要改代码**。
- **不预填任何姓名**：建档表、人名正字总表等一律生成空占位模板。
  AI 不会、也不许从记忆或画像里推断并写入具体人名。
- **包内示例均已泛化**：出现的「某年某月」「甲某乙某」「境外乙」「某种腿部疾患」
  等均为占位写法，不含任何真实第三人的可识别信息。

## 语言与分支（欢迎新增语种）

**方法本身不绑定语言。** 访谈、时间线、存疑标注、照片断代、四层质检——这些在
任何语言下都成立。真正需要本地化的是**内容**：

- **访谈问题**：必须改写成本国老人真能回答的版本（本国的年代、制度、职业、
  生活细节）。字面直译出来的问题，本国的老人答不上来。
- **断代线索**：服饰、器物、发式、建筑——中国年代的速查表要换成你们国家的。
- **人名规则**：「字辈」是汉人家族的命名习惯，别的文化应替换成自己的命名惯例，
  不适用就删掉该节并说明。

Canonical 版本是**简体中文**（根目录下 `SKILL.md`）。新增语种请放
`i18n/<locale>/`，规范见 **[CONTRIBUTING.md](CONTRIBUTING.md)**。

> ⚠️ 我们**不接受访谈问题的字面直译**。为本国老人**重写**问题，才是真正的贡献。
