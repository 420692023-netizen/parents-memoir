# 四层质检清单（成稿交付前必跑）

> 借鉴"测试金字塔"思路：从硬性规则到主观温度，层层递进。任何一层不过，修复后重跑该层。质检报告随成稿一并交付用户。

## L1 史实一致性（硬规则层）

- [ ] 全文年代可串成一条自洽时间线（年龄×年份不出现矛盾）
- [ ] 人名、地名、单位名前后写法统一（含"存疑待核"标注的，单独列出清单）
- [ ] 每个事件都能回溯到素材出处（抽查 5 处，指出对应素材段落）
- [ ] 无任何素材之外的新增"事实"（重点检查：对话、数字、他人评价）
- [ ] 时代背景表述不越界（只作背景，无史实断言）

**通过标准**：全部 ✅；存疑处均已显式标注，而非静默处理。

## L2 原味保留度（人格层）

- [ ] 每章至少 2-3 处传主原话直引（引号内文字与口述稿逐字一致，含语气词）
- [ ] 方言词、口头禅保留原字并有括号注释
- [ ] 传主的标志性表达（其独有比喻、惯用句式）在文中至少出现 3 次
- [ ] 抽查 3 个段落：遮住人名，熟悉传主的人能否认出"这是他/她说的话"？
- [ ] 价值判断与人生感慨均可归属到传主原话，无整理者代立的"中心思想"

**通过标准**：直引数量达标，无"把口语洗成书面语"的段落。

## L3 去 AI 腔（文字层）

- [ ] 全文检索 fidelity-rules.md 禁忌词表，零命中
- [ ] 无连续三段以上的排比抒情
- [ ] 无"万能开头"（他出生在一个普通的家庭/在那个年代……）
- [ ] 形容词密度抽查：任取 500 字，空洞形容词（伟大、无私、深沉等）≤2 个，其余为具体名词动词
- [ ] 无"让我们""不难发现""综上"类转场套话

**通过标准**：禁忌词零命中，抽查段全过。

## L4 子女试读温度感（终审层）

以委托人（子女）视角通读全文，回答：

- [ ] 读完能否"看见"这个人——有画面、有声音，而不只是生平简历？
- [ ] 至少有一处让人"鼻子一酸"，且该处来自真实细节而非抒情形容词？
- [ ] 传主的"不完美"是否在场（固执、节俭到抠门、脾气）？一个毫无缺点的人是 AI 写的最大破绽。
- [ ] 收尾是否落在传主自己的话上，而不是整理者的拔高？
- [ ] 如果把书名换成别人的名字，这本书还成立吗？（成立=写失败了，人物没有独特性）

**通过标准**：整体感觉是"一位晚辈认真记下了长辈的一生"，而非"AI 产出的感动范文"。

## 质检报告格式

```
## 家传质检报告（第 N 稿）
L1 史实一致性：✅/❌（存疑待核清单：X 处，附后）
L2 原味保留度：✅/❌（原话直引 X 处；需补充章节：……）
L3 去 AI 腔：✅/❌（命中词与位置：……已修复/待修复）
L4 子女试读：✅/❌（断点/失真段落：……）
总评：可交付 / 需返工（列出最优先修复的 1-3 项）
需委托人确认事项：（史实存疑、授权、隐私信息处理）
```
