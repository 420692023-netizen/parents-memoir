# 六章全书结构模板与各章写作要点

> 第三幕章节规划时使用。默认六章结构适用于大多数传主；按素材量可合并（如素材少时四章：故乡→立业→家庭→尾声）。

## 全书默认结构

```
序（子女写，"为什么要记"，800-1200 字）
第一章　故乡与童年（出生—离家前）
第二章　立业（第一份工作—职业高峰）
第三章　成家（婚恋—子女出生—家庭岁月）
第四章　风雨（人生低谷与转折，如下岗、变故、疾病）
第五章　为人父母/为人子女（对上一代与下一代的双向情感）
尾声　他的话（人生信条 + 想留给后辈的话 + 金句集）
附录　家谱简表 / 老照片说明 / 原话金句集
```

## 各章写作要点

**序**：只写三件事——为什么现在记、怎么记的（访谈过程一句话）、这本书的立场（"没有一个字是替他想的"）。不抒情、不预告泪点。

**第一章·故乡**：时间坐标打头；写"物"多于写"情"（吃食、衣裳、房屋、声音气味）；祖辈信息通常稀缺，稀缺本身如实写（"关于他的父亲，他只留下一句话"）。

**第二章·立业**：第一天的细节是黄金（报到穿着、第一句话、师傅其人）；职业信条在此章立住，作为全书复调在后续章节呼应。

**第三章·成家**：婚恋故事按"认识—定亲—成家—难关—相守"推进；配偶是独立的人，不只写"贤惠"，要写出她/他的具体动作与性格。

**第四章·风雨**：低谷章节最忌卖惨与拔高；只写事实与传主当时的应对，让尊严自己显现。传主不愿讲的段落，写明"他不愿多讲"即止。

**第五章·为人**：双向视角——他如何送走了上一代（遗憾与未尽），又如何送下一代远行（骄傲与失落）；委托人（子女）可在此章以"我"的视角出现一次。

**尾声**：只用传主原话收束全书；金句集按主题排列（关于吃苦/关于家/关于做人）；最后一句留给传主，整理者不说话。

**附录**：家谱简表三代以内即可；老照片说明含"时间-地点-人物-背后一句故事"；金句集宁少勿滥（10-20 条）。
