# 原话保真写作规则 + 回忆录 AI 腔禁忌词表

> 第三幕写作的强制规则。目标：成稿读起来像"这位老人的人生"，而不是"AI 写的标准好人好事"。

## 一、保真五原则

1. **事实零虚构。** 所有事件、年代、人名、地点、因果必须来自素材或用户确认。没有素材的环节写"这一段他已记不真切"或直接跳过，绝不补写"合理想象"。
2. **原话直接引。** 传主有原话的段落，优先用引号原样呈现（含口头禅、语气词、方言字），叙述者只做串联。每章至少保留 2-3 处原话直引。方言词保留原写法，后加括号注释，如"夜了个（昨天）"。
3. **判断归本人。** 价值判断、人生感慨只写传主本人说过的；整理者不做升华、不代替总结"他这一生告诉我们……"。需要点题时，用传主自己的金句。
4. **结构可调，语感不动。** 允许调整时间顺序、合并同类事件、删去重复唠叨；但不允许把口语句改写成书面句（"俺寻思这事儿不赖"不得改成"他认为这件事很好"）。
5. **时代只做背景板。** 提供时代背景（如"那年月买肉要票"）只用一两句交代，服务理解；不展开历史科普，不替传主评价时代。

## 二、AI 腔禁忌词表（出现即改写）

以下空洞抒情词在回忆录中一律禁用或替换为具体事实：

- 「岁月静好」「时光荏苒」「光阴似箭」「白驹过隙」→ 直接写哪一年、什么事
- 「含辛茹苦」「任劳任怨」「勤勤恳恳」→ 用一个具体事例替代形容词
- 「无私的爱」「深沉的父爱/母爱」→ 写具体动作（凌晨排队、省下半碗饭）
- 「命运的齿轮开始转动」「历史的洪流」→ 删
- 「回首往事，他感慨万千」→ 写他具体说了什么
- 「在那个激情燃烧的岁月」→ 写具体年月
- 「诠释了什么是……」「这就是……的最好注脚」→ 删，让读者自己得出结论
- 「首先、其次、最后」「综上所述」「值得一提的是」「不难发现」→ 散文叙述，自然转场
- 连续排比抒情三段以上 → 拆散，落地到事实

## 三、允许的"整理动作"白名单

- 按时间线重排叙述顺序
- 给同一事件的多处零散讲述做合并。**多稿取舍优先级**：细节更具体者为准（有物件、动作、对话的一稿）；两稿均具体但冲突时，并列保留并标存疑，不私自择一；传主情绪更投入的一稿，其原话优先直引
- 删除纯粹重复的口头碎句（"然后呢然后呢"）
- 为方言、已消失的事物（工分、粮票、BB机）加一行括号小注
- 在章首加一两句"时间坐标"（例：1968 年，他 18 岁，第一次离开县城）
- 把矛盾处并列保留并标注（例：关于进厂年份，他两次说法不一，一说 1976，一说 1978——存疑待核）
- 传主的"沉默"也是素材："不肯讲""摆摆手""记不清"可如实写入，这比任何形容词更能刻画人

## 四、章内推荐节奏

- 开头：时间坐标 + 一个具体场景切入（不用"他出生在一个普通家庭"这类万能开头）
- 中段：事件叙述与原话直引交替，一段一事
- 章尾：可用传主原话收束；不强行拔高
- 全文允许保留"记不清"——真实的留白比圆满的编造更动人

## 五、叙述者视角规则（多人拼凑与已故场景必守）

1. **谁的记忆谁说话。** 传主口述章节用传主视角（"我那年进的厂"或第三人称"她那年在车间"）；子女提供的记忆必须放在子女视角章，以"我记得"起笔或章首注明"本章由子女回忆整理"。
2. **绝不视角混排。** 禁止把子女记忆改写成传主自述口吻（"我妈说她省口粮给我哥"不得写成传主自述"我省口粮给大儿子"）——这是变相虚构。
3. **来源可溯。** 质检时，子女视角章的每个事实同样执行逐句回溯，出处记到具体来源人。
4. **冲突呈现。** 家庭成员记忆冲突时，并列呈现并注明各自出处（"女儿记得是五八年；儿子记得是六〇年——樟木箱里的蓝布包袱都在，年份已无从对证"），这本身是好文字。

## 六、已故传主基调锚定（防悼文化）

- 正文章节写"她怎么活的"，不写"我们多想她"；哀思只允许集中在序言与尾声。
- 禁用悼文句式：「音容笑貌犹在」「永远活在我们心中」「驾鹤西去」「一生的奉献」「我们永远怀念您」→ 改为具体事实与传主原话。
- 离世一事本身克制处理：一章之内交代，以家人记忆中的具体细节收束（最后住的屋子、留下的话、留下的物件），不渲染病榻与弥留细节，除非委托人明确要求记录。
- 落款与献词页可以抒情，正文章节保持平实——平实是对逝者更大的敬意。
